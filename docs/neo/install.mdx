Slave Agent neo is a full browser, so installing it works like installing Chrome or Firefox. Download it, drag it across or run the installer, and open it.

## macOS

<Tabs>
  <Tab title="Homebrew">
    ```sh
    brew tap slave agent-ai/tap
    brew install --cask slave agent-neo
    ```

    The tap is needed because Slave Agent neo is not in Homebrew's own cask repository yet. Once it is, the same `brew install --cask slave agent-neo` keeps working and the tap becomes optional.

    Upgrade with `brew upgrade --cask slave agent-neo`, though the browser also updates itself.
  </Tab>
  <Tab title="Direct download">
    <Steps>
      <Step title="Open the disk image">
        Double-click the downloaded `SlaveAgent_neo.dmg`.
      </Step>
      <Step title="Drag it to Applications">
        Drag **Slave Agent neo** onto the Applications folder in the same window, then eject the disk image.
      </Step>
      <Step title="Open it">
        Launch Slave Agent neo from Applications or Spotlight. On first launch it will offer to import bookmarks and passwords from your existing browser.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Windows

<Steps>
  <Step title="Run the installer">
    Double-click the downloaded `SlaveAgent_neo_installer.exe` and follow the prompts.
  </Step>
  <Step title="Open it">
    Launch Slave Agent neo from the Start menu.
  </Step>
</Steps>

## Keeping it up to date

Slave Agent neo updates itself. It checks for new versions in the background and installs them on the next restart, so there is nothing to do after the first install.

<Note>
There is no Linux build of Slave Agent neo yet. Slave Agent, the browser for humans, does ship for Linux. See [Install Slave Agent](/slave agent) if that is what you are after.
</Note>
