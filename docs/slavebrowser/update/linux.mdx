---
title: "Update on Linux"
description: "How to update Slave Agent on Linux"
---

<Steps>
  <Step title="Check for updates">
    Click the **Slave Agent Feedback** extension (bug icon) in the toolbar, then click **Check for Updates**.

    <Frame>
      <img src="/images/check-for-updates.png" alt="Slave Agent Feedback extension showing Check for Updates button" />
    </Frame>
  </Step>

  <Step title="Download the latest version">
    Download the Linux build from [GitHub Releases](https://github.com/slave agent-ai/Slave Agent/releases).
  </Step>

  <Step title="Install">
    Extract and run the binary. Your settings and data will be preserved.
  </Step>
</Steps>
